# Robot Romance: One-Line Pickup Lines for AI

A tiny TypeScript program (Node 22.18+, stdlib only) that writes one original
single-line pickup line aimed at a robot/AI to `entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`).
